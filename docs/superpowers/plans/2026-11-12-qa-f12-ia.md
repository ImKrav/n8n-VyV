# F12 — Ítem 13: IA aplicada al testing (Playwright MCP)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cada integrante usa Playwright MCP, con un agente de IA, para explorar, automatizar y validar flujos web de sus funcionalidades. El resultado son pruebas Playwright generadas y ejecutadas, con evidencias de su aporte y sus limitaciones.

**Architecture:** El servidor `@playwright/mcp` (versión fijada) se registra para Claude Code con un archivo `.mcp.json` de alcance de proyecto dentro de `qa/13-ia/`. El agente navega la instancia local, propone el flujo y escribe una prueba en `qa/13-ia/generadas/`; después la prueba se ejecuta **fuera** del agente con `npx playwright test`, para que el resultado no dependa de la IA. Stagehand y DeepEval quedan fuera por la decisión D4 y se declaran como diferencia.

**Rama:** `qa/fase-12-ia`. **Paralela a F9–F11.** **Fecha límite:** 15/11/2026.
