# Evidencias

Convención de identificador: `EV-<ítem>-<id>-<n>`, por ejemplo `EV-06-CP-WF-01-01-1`.
Ruta: `qa/evidencias/<ítem>/` (por ejemplo `qa/evidencias/06/`). Los JUnit van en `qa/evidencias/<ítem>/junit/`.

Reglas: sin secretos (las HAR se guardan sin cabeceras `cookie` ni `authorization`) y sin datos personales reales.
